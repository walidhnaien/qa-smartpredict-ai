# AI Quality Report Test Fixture

quality-report.fixture.json is a synthetic test fixture.

It contains fictional identifiers, fictional execution dates
and generic QA narratives.

Selected numerical constants and governance states are retained
for regression testing.

The REAL mode value represents a simulated API response for
a completed REAL workflow. It does not represent an actual run.

The fixture must not be used as production evidence or as
proof of semantic correctness.

Original workflow results and qualification evidence must
remain outside the published source repository.
